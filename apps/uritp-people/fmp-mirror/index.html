Layout Renders

Each render is an HTML page that boots sql.js, loads the schema + seed, and draws one FileMaker layout using canonical object library families and theme vectors. No ad-hoc styling.

Verification

schema.sql tracks the DDR. When a new DDR drops:

  • Pipeline writes STATE.md
  • Diff STATE.md against schema.sql
  • Stale fields / tables / relationships surface as gaps
  • schema.sql updates, renders break visibly if the data moved

Constraints

  • Data: renders query schema.sql only. No invented fields.
  • Visual: renders use canonical object library families only. No ad-hoc objects.
  • Theme: renders consume theme vectors (colors, typography, forms, spacing). No inline colors.
  • Seed: synthetic data in the repo. Real data stays in ClickUp / FileMaker.
