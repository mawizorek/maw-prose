# APP_LAYOUTS

⛔ **NOT BUILT, and the name is not settled.**

This page described a layout catalog and a navigation menu that `URITP People.fmp12` does not have. No table, no `APP_MENU` layout, no menu scripts.

The table half of the catalog was built as [Target_Tables](@uritp-people-table-target-tables) and Michael ruled that name stands (D-049). The layout half has no live counterpart, so there is no built name to follow: whether it becomes `Target_Layouts` for symmetry with the table, or keeps `APP_LAYOUTS` from D-043, is **unruled**, and inventing one here would be a guess dressed as a fact.

The specification still lives in [the app catalog](@fmp-app-catalog), under the provisional name, along with `APP_GoToLayout` and `APP_OpenMenu`. What the menu was going to show, once there is one: the people-facing layouts, with the utility forms the scripts navigate to kept out of it.

Kept rather than deleted so a reader arriving from D-043 or the catalog standard lands on an explanation instead of a 404.
