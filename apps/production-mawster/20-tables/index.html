    For the Production Calendars¶

    [PRODUCTION_CALENDARS] - One calendar per production (usually - exceptions might be the same production in two different time blocks).
    - Joining entity to output.

    [CALENDAR_EMPHASIS] - N typed callouts per calendar. range mode = typed dates; event mode = anchored to a STANDARD_EVENT so it survives a reschedule. - Priority-resolved. Replaced the fixed highlight/lowlight pairs. - ⬜ Michael's note: use this for HIDE as well. Not done — HIDE is currently a range pair on the calendar because hide is EXISTENCE (stamped, changes the found set) while emphasis is STYLING (resolved live). Folding it in means deciding which verb wins.

    [WEEKS]
    - Parent is the CALENDAR, not the production. [WORKDAYS] - The printed grid cell. Generated, never typed.

    [STANDARD_EVENTS]To be confirmed
    - For defining custom events. Nothing in the app should break if there are no standard events. That is to say that all imported events are handled elegantly regardless of its existence in STANDARD_EVENTS. But STANDARD_EVENTS should automatically be linked during import and might SKIN additionally or help us export specialized reports or create workflow notes from canonical definitions. - ⭐ Also the anchor for event-mode emphasis.

    [EVENTS] - What gets printed. UPSERT on TaskID + fkProduction, never TaskID alone. [import_SESSIONS] - One pull. The session IS the snapshot. - see also {#import-events}

    For the Contact Sheets¶

    [ROLES] - The role LIBRARY. [ASSIGNMENTS] - production x role x NULLABLE person. The credit line. The contact sheet.

    Exporting — the print hub¶

    ⚠️ PRINT or EXPORT — the vocabulary is split and this section is where it shows

    Every label below says PRINT_. Every file in 20-tables/ says EXPORT_. The @ids mostly kept the PRINT spelling through that rename, so the links work and the words disagree.

    ✅ @table-print-presets was DEAD and is fixed (2026-09-30) — EXPORT_PRESETS.md carries id: table-export-presets, the one id that drifted on both sides at once. 🚫 The four visible labels are deliberately NOT renamed: renaming one of five leaves the section half-converted, which is the state that produced this defect. One decision, one pass, or leave it.

    [PRINT_PRESETS] - HOW to output. Reusable across productions. [PRINT_SETS] - WHAT to output, batched. One reserved SCRATCH set resets from a template set on entry. [PRINT_SET_ITEMS] - One produced document. Overrides live here; empty means inherit from the preset. [PRINT_SESSIONS] - WHAT HAPPENED. One row per PDF. Carries fkPreset.

    [EDITIONS]To be confirmed - Prelim | For Bid Only | Final. A PRINT is a VERSION of an edition. [VERSIONS]To be confirmed - Parts of an edition.
