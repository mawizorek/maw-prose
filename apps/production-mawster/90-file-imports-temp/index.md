# File Imports Inbox

⚠️ **`status: hidden`, deliberately.** Working material that gets culled, so it must not render into a published site — a 19KB paste of somebody's script steps is not a document.

(`draft` was tried first and is **not a legal status value**. The legal set is `gated` · `hidden` · `public` · `unlisted`, and an illegal value drops the page entirely rather than hiding it, which looks identical until you need the link to work.)

The REVIEW of an import belongs in the app proper; only the raw paste lives here.
