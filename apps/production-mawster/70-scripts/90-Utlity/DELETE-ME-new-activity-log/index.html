    🔴 DELETE ME — 90-Utlity/NEW-ACTIVITY-LOG.md¶

    Zero-byte placeholder in a misspelled folder. Superseded by UTIL · Run Start. Michael deletes.

    Flagged 2026-08-10. Do not add content to this file. Do not reuse the folder.

    What it was: a zero-byte placeholder, created when 70-scripts/ was first scaffolded. It has never held a single character.

    Keeper: UTIL · Run Start and UTIL · Run End. The retired script it was standing in for is archived at new_UTILITY_LOG.

    ⚠️ Its NAME is also wrong, and that matters more than the emptiness. There is no "activity log" in this app — the table is UTILITY_LOGS, and activity log is the name of a completely different artifact in a different system (an agent's own activity-log.md in brain-config). A placeholder file naming a table that does not exist is a claim, and an empty file makes it an unfalsifiable one.

    Why the folder goes, not just this file: the misspelling (Utlity), the one-taxonomy ruling on the scripts index, and the empty-container rule — full argument on the sibling flag.

    🚫 Renamed, not deleted. Per the Deletion-Flag Gate, flagging is the agent's job and deleting is Michael's. Delete the whole 90-Utlity/ folder.
