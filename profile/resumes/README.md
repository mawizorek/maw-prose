# Resumes

*One per lane, not one per employer. Content last checked 10 October 2026.*

A resume here is a lane, reused across every posting that screens the same way. Which posting it was sent to, and when, is a record of the job search and lives on that application's task in ClickUp, never in a file name here.

Each page is the text of a one-page resume. The phone number is added at export, so it is never committed to this repo.
