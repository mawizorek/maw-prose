# maw-prose

Notes, handbooks, and standards. Written as **handoff docs** for a designer starting cold, a new hire, or whoever holds the role next.

**Private.** Write freely.

---

## What is here

### `handbooks/`

- **[Head Electrician](./handbooks/head-electrician/)** what the role owes and how it runs, broken up by production phase. [The job](./handbooks/head-electrician/the-job.md) and [deliverables](./handbooks/head-electrician/deliverables.md) are real; the six phase notes and inventory are **skeletons, empty on purpose**, waiting to be dictated.

### `standards/`

- **[Vectorworks](./standards/vectorworks/)** how our show files are set up. Layers vs. classes, the reference model, the origin, symbol authoring, the DWG hedge. **Read before opening a show file.**

## Before you add anything

**[CONVENTIONS.md](./CONVENTIONS.md)** the shape, how to write these, where numbers live, and the one test for whether a file belongs here at all.

**[DECISIONS.md](./DECISIONS.md)** settled calls, one line each.

Open questions live in ClickUp, not in this repo. A `- [ ]` here is dead text; nobody can answer it.
