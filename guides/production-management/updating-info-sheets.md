# Updating Info Sheets
> The bridge doc. Carries dates FROM production calendar AND personnel FROM contact sheet.

## What It Is
One-page production summary: key dates, design deadlines, cast/crew contacts, course info, venue. The doc you forget because "the source already updated... right?"

## Who Maintains
- **Created by:** Nigel (Word template via Dropbox)
- **Kept current by:** PM

## Where It Lives
| Platform | Path Pattern |
|----------|-------------|
| Dropbox | `productions/z[YY-YY]/[show]/` (root of show folder) |
| Shared via | PDF to company; Word stays internal |

## Fields

**From Production Calendar:**
- All Key Dates (auditions through strike)
- All Other Dates (design deadlines, fittings, load-in)
- Academic calendar markers (breaks, special weekends)

**From Contact Sheet:**
- Director, designers, SM, PM, TD
- Select cast (leads or full, production-dependent)

**Unique to Info Sheet:**
- Course numbers
- Cast size
- Venue/space
- Performance run summary

## Update Triggers
- Any date change (inherits all calendar triggers)
- Any personnel change (inherits all contact triggers)
- Course number assignment
- Cast size finalized

## Cross-References
This doc is DOWNSTREAM. When updating:
- Calendar change → update info sheet Key Dates / Other Dates
- Contact change → update info sheet personnel section
- Info sheet should NEVER be the source; if it disagrees, calendar/contacts win

## Audit Checklist
- [ ] Key Dates match Google Calendar exactly
- [ ] Other Dates match Google Calendar exactly
- [ ] Personnel match current contact sheet
- [ ] Course numbers confirmed with registrar
- [ ] Cast size matches actual casting
- [ ] PDF version matches Word version in Dropbox
