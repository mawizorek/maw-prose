# Production phases

*What happens during each phase of a production. Followed in the moment, by whoever is running it.*

A production moves through the same sequence every time, and the sequence is the industry's rather than the department's: preseason, paperwork prep, load-in, tech, show run, strike. Inventory is a standing duty rather than a phase. Every theatre loads in and strikes, which is why these notes travel and a semester calendar does not.
