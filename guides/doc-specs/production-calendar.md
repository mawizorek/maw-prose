# Production Calendar

> The canonical timeline for a production. Every date, deadline, and milestone in one place.

**Department:** PM
**Steward:** Production Manager
**Platform:** Google Calendar (shared) + Dropbox (PDF snapshot for distribution)
**Frequency:** per-production (living document from first planning meeting through strike)

## Fields

### Season context
- Production title
- Season designation
- Academic calendar constraints (breaks, finals, move-in/out)

### Key milestones (single dates)
- Season announced
- Design team assigned
- First production meeting
- Audition dates
- Callbacks
- Cast list posted
- First rehearsal (read-through)
- Designer run
- Paper tech
- Dry tech
- First tech (cue-to-cue)
- Sitzprobe (if applicable)
- First dress
- Final dress
- Opening night
- Closing night
- Strike
- Post-mortem / debrief

### Recurring blocks
- Rehearsal pattern (days, times, location)
- Production meeting cadence
- Build hours (shop schedule)
- Design presentation dates

### Deadlines
- Scenic design due
- Lighting design due
- Sound design due
- Costume design due
- Props list due
- Program copy due
- Marketing photo call
- Poster/publicity deadline
- Ticket on-sale date

### Special dates
- Load-in date(s)
- Focus call
- Sound level-set
- Fight/intimacy rehearsal dates
- Photo call
- Invited dress / preview
- Talkback dates
- Donor/VIP events

## Sources

| Field group | Source |
|-------------|--------|
| Academic constraints | Registrar / department academic calendar |
| Milestones | PM + director (negotiated at first production meeting) |
| Rehearsal pattern | Director preference + venue availability |
| Design deadlines | Department standards + TD/PM negotiation |
| Marketing deadlines | Marketing coordinator / department policy |
| Special dates | Director + designers (emerge during process) |

## Downstream

- **Info sheet** — pulls all dates (info sheet is a SUMMARY of this calendar)
- **Crew call** — each crew call references a specific date FROM this calendar
- **Rehearsal reports** — each report is keyed to a rehearsal date from this calendar
- **Marketing materials** — pulls performance dates, on-sale date
- **Box office** — pulls performance dates for ticket setup
- **Facilities requests** — pulls load-in, tech, performance, strike dates
