# Letterhead

> Branded header/footer template for official URITP correspondence and documents.

**Department:** General
**Steward:** Production Manager
**Platform:** Word / Google Docs
**Frequency:** standing (updated when branding or contact info changes)

## Fields

- Organization name
- Logo (file reference)
- Tagline / subtitle
- Season line (e.g. "2026-27 Season")
- Mailing address
- Phone number
- Email (general / office)
- Website URL
- Social media handles
- Footer disclaimer / legal line

## Sources

| Field | Source |
|-------|--------|
| Logo | Brand assets folder (Dropbox) |
| Season line | Production calendar |
| Contact info | Contact sheet (office section) |
| Social handles | Marketing / admin |

## Downstream

- Any official correspondence
- Contracts and offer letters
- Press releases
- Program inserts (when URITP-branded)
