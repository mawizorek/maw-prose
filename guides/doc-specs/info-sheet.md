# Info Sheet

> The master one-pager for a production: who, what, when, where. Distributed to full company at first rehearsal.

**Department:** PM  
**Steward:** Production Manager  
**Platform:** Dropbox (`.docx` working file, PDF for distribution)  
**Frequency:** per-production

---

## Filename Convention

`{ABBREV}.Info Sheet.{SEMESTER}{YY}.docx`

- ABBREV = production abbreviation (BL, TM, TS, OA, etc.)
- SEMESTER = F (Fall) or S (Spring)
- YY = two-digit year

---

## Structure (top to bottom, no deviation)

### 1. Header Block

```
{Semester} {Year}
{Slot}: {Course Code(s)} (prev. {Legacy Code})
{Title}
[{Subtitle/Devising Attribution}]
by {Playwright/Creator}
```

- Slot = "Play 1" / "Play 2" / "One Acts S27" etc.
- Subtitle line only when applicable (devised work, alternate title)
- Course codes include current AND legacy when both exist

### 2. Creative Team

Tab-aligned: Role on left, Name in ALL CAPS on right.

**Always present:**
- Director
- Scenic Designer
- Costume Designer
- Lighting Designer
- Sound Designer [& Original Music]
- Voice & Acting Coach
- Intimacy Director

**Conditional (include when role is filled):**
- Choreographer
- Fight Director
- Dramaturg
- Projections Designer
- Props Designer
- Hair & Makeup Designer

### 3. Production Team

Same format as Creative Team.

**Always present:**
- Producer
- Production Manager
- Technical Director
- Stage Manager
- Assistant Stage Manager(s)

**Conditional:**
- Associate Director
- Assistant Director
- Dialect Coach

### 4. Key Dates

All dates formatted as: `Weekday, Month DD`

| Field | Notes |
|-------|-------|
| First Rehearsal | Always present |
| Designer Run | Always present |
| Tech Start | Always present |
| Dress Rehearsals | Range (start - end) |
| Opening Night | Always present |
| Closing Night | Always present |
| Strike | Always present |

### 5. Other Dates (conditional)

Include only when applicable to the production:

- Auditions
- Callbacks
- Reads / Workshops
- Load-In
- Photo Call
- Invited Dress
- Post-Mortem
- Special Events (talkbacks, master classes)

---

## Variant Rules

### One Acts (OA)
- Header lists all titles separated by " / "
- Multiple directors listed under single Creative Team block
- Key Dates may show per-piece tech schedule
- "One Acts" replaces slot designation

### Development Productions
- Header includes "Development" in slot line
- Playwright/Creator listed as "Devised by [Company]" when applicable
- May omit some conditional roles (less design team)
- Rehearsal process dates may differ from standard timeline

---

## Formatting Rules

- Names always in ALL CAPS
- Empty roles stay listed with TBD (never omit an "always present" role)
- Date format: `Weekday, Month DD` (no year, implied by header)
- Single page strongly preferred; two pages acceptable for complex shows
- University/department branding at top (logo or text header)

---

## Sources

| Field | Source |
|-------|--------|
| Title, playwright | Season selection (Artistic Director decision) |
| Slot, course codes | Registrar / department schedule |
| Creative team | Department head assignments |
| Production team | PM assignments |
| Key dates | Production calendar (master schedule) |
| Venue | Space allocation (TD / facilities) |

## Downstream

- **Contact sheet**: pulls production title, creative/production team names
- **Crew call**: pulls key dates, venue
- **Program**: pulls title, playwright, creative team, cast
- **Marketing materials**: pulls title, dates, venue, content advisories
- **Course syllabus**: pulls key dates, course codes
