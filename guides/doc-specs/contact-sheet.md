# Contact Sheet

> The complete personnel directory for a production. Every person involved and how to reach them.

**Department:** PM / SM (co-stewarded)
**Steward:** Stage Manager (maintains), Production Manager (initiates)
**Platform:** Dropbox (shared Google Sheet for some productions)
**Frequency:** per-production (living document, updated as company changes)

## Fields

### Per-person entry
- Full name
- Pronouns
- Role / position (e.g. "Lighting Designer" or "Ensemble")
- Section (Staff / Cast / Crew)
- Email (primary)
- Phone number
- Emergency contact name
- Emergency contact phone
- Emergency contact relationship
- Conflicts / availability notes (rehearsal period only)

### Document-level
- Production title
- Season
- Last updated date
- SM name (who maintains this copy)

### Sections (grouping)
- **Production team** — director, designers, PM, TD, dramaturg
- **Stage management** — SM, ASMs, PSM
- **Cast** — principals and ensemble
- **Running crew** — board ops, deck crew, wardrobe, fly crew
- **Front of house** — house manager (if tracked here)
- **External** — venue contacts, rental houses, guest artists

## Sources

| Field | Source |
|-------|--------|
| Names + roles | Casting list (post-audition), department assignments |
| Contact info | Collected directly from individuals (first rehearsal form) |
| Emergency contacts | Collected directly (first rehearsal form) |
| Conflicts | Collected directly (audition form or first rehearsal) |
| External contacts | PM knowledge / venue agreements |

## Downstream

- **Info sheet** — pulls key company names (director, PM, SM, designers)
- **Crew call** — pulls personnel list for who's called
- **Program** — pulls cast/crew names for printed credits
- **Emergency procedures** — references emergency contacts
- **Email/communication lists** — built from this roster
