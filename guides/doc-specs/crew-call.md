# Crew Call

> The schedule and personnel list for a specific work session. Who needs to be where, when, doing what.

**Department:** SM
**Steward:** Stage Manager (issues), Production Manager (approves schedule)
**Platform:** Dropbox (PDF) or email
**Frequency:** per-call (one document per tech/work session; may be issued daily during tech week)

## Fields

### Header
- Production title
- Call type (work call / tech / dress / performance / strike / special)
- Date
- Location
- Doors / building access time
- Call time
- Estimated end time
- Issued by (SM name)
- Issued date

### Personnel
- Department heads called (list by name + role)
- Running crew called (list by position)
- Cast called (full company or partial; if partial, list names)
- Other personnel (front of house, guest artists, observers)

### Schedule
- Activity breakdown by time block (e.g. "6:00-6:30 — preset; 6:30-7:00 — top of show cue-to-cue")
- Meal break time (if applicable)
- Breaks (10-min break cadence per Equity/department rules)

### Work to accomplish
- Goals for the call (what success looks like)
- Carryover from previous call (what didn't get finished)
- Priority order (if time runs short, what gets cut)

### Notes
- Safety notes (fog, haze, weapons, fly cues, pyro)
- Costume/quick-change needs for this call
- Props preset requirements
- Special equipment needed (lifts, ladders, followspots)
- Parking/access notes (if non-standard)

## Sources

| Field | Source |
|-------|--------|
| Date + time | Production calendar (canonical) |
| Personnel | Contact sheet (canonical roster) + director/SM decisions |
| Schedule/activities | SM + director planning |
| Safety notes | Risk assessment + SM observation |
| Goals/carryover | Previous day's performance/tech report |

## Downstream

- **Rehearsal/tech report** — the report for this session references which call it was
- **Time tracking** — hours worked keyed to call times
- **Performance report** — performance calls feed directly into the post-show report
